## 使用与边界

打开 http://127.0.0.1:5173 并注册自己的普通账号。管理员由本机操作者运行 `python scripts/create_admin.py --username admin`，交互式输入密码。真实机器人需要在推送设置中提供自己的 Webhook。

Docker 容器、生产部署、多实例调度、负载与容灾尚未验证。Milvus 语义去重、RocketMQ 和任意节点 checkpoint 回放不属于本次验收。静态页面解析不保证登录站点或依赖 JavaScript 的正文可用。
